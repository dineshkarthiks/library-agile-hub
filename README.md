# Smart Library Management System

## 1. Introduction
The Smart Library Management System streamlines core library operations including book cataloging, member registration, issue & return tracking, overdue fines, and reservations.

## 2. Objectives
- Maintain an accurate digital book catalog and availability status.
- Automate book issue, return, and fine calculation records.
- Track member borrowing history and reservation queues.
- Generate usage and inventory analytics reports.

## 3. Main Modules
- Book Catalog & Inventory Management
- Member Registration & Authentication
- Book Issue & Return Tracking
- Automated Fine Calculation & Alerts
- Search, Filter & Book Reservations
- Admin Dashboard & Usage Reports

## 4. Tools Used
- GitHub Projects (Kanban Board & Insights)
- GitHub Issues (Task & Bug Tracking)
- GitHub Labels & Built-in Workflows

## 5. Agile Methodology
This project follows the Kanban methodology with three workflow stages: Todo, In Progress, and Done. Tasks are prioritised using labels and monitored through GitHub Insights.
